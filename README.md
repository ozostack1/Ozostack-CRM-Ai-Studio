# OzoStack CRM - AI Studio & CEO Command Center

A modern, production-grade enterprise CRM and executive business operations suite built with **React 19**, **Vite**, **TypeScript**, and **Tailwind CSS**.

---

## 🚀 Key Features

- **Executive CEO Command Center**: Real-time revenue velocity, ARR & MRR goals tracking, financial health scorecards, and radial KPI gauges.
- **Multi-Currency System**: Global currency selector (USD, INR, EUR, GBP, AED, CAD, AUD, JPY, SGD) with instant, uniform format conversion across all modules.
- **Sales & Pipeline Management**: End-to-end Lead capture, Deal pipelines, Contacts, and Company CRM profiles.
- **Projects & Task Delivery**: Interactive Kanban boards, task timelines, subtask checklists, and time tracking.
- **Interactive Header Calendar & Scheduler**: Dynamic live-date calendar with monthly navigation, day-level event inspection, and two-way sync with the Events & Calendar engine.
- **Enterprise Financial Documents Engine**:
  - Invoices, Price Quotations, and Master Services Contracts (MSA).
  - High-fidelity PDF generation tailored for both **A4** and **Letter** paper sizes.
  - Interactive editing for terms, bank remittance, line items, and approval states.
- **AI Automation & AI Studio**: Intelligent workflows, automated notifications, and AI-powered operational tools.
- **Role-Based Access Control (RBAC)**: Comprehensive permission scopes (Super Admin, Finance, HR, Department Manager, Staff).

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite 8
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Animations**: Motion
- **AI Integration**: Google GenAI SDK

## 🏁 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# Clone repository
git clone https://github.com/ozostack1/Ozostack-CRM-Ai-Studio.git
cd Ozostack-CRM-Ai-Studio

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Build & Production

```bash
# Typecheck
npm run lint

# Production bundle build
npm run build

# Preview build locally
npm run preview
```
